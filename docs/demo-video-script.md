# CodeTrace 码迹 · 演示视频脚本（3 分钟）

> 目标观众：**高校编程课教师与教务管理者**。
> 核心信息只有一句：**它看的是"代码怎么产生的"，而且不会冤枉学生。**

---

## 分镜

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0:00–0:12 | 分屏：左边是真学生现场敲代码，右边是粘贴 AI 结果 | 字幕：**"这两份最终代码，看起来都像正常作业"** |
| 0:12–0:25 | 传统相似度工具界面：两份代码相似度 12%，判定"无异常" | 旁白："现有相似度工具判不出来——因为它们只看最终文本。" |
| 0:25–0:40 | CodeTrace 回放界面：右边这份的编辑轨迹是一条长粘贴 | 字幕：**"但过程不一样。"** |
| 0:40–1:00 | 演化图动画：节点是快照、边是编辑操作；粘贴那一下出现一条粗边 | 旁白："我们把编辑事件变成一张代码语义演化图，粘贴、突变、调试循环都会在图上留下痕迹。" |
| 1:00–1:15 | 五个通道的分值条（P1 粘入 1.00 / P2 突变 0.00 / P3 调试 0.59 …） | 字幕：**五个通道，各自打分** |
| 1:15–1:30 | 结论卡片：**"需复核"**（不是"作弊"） | 旁白："注意，它给的是'需复核'，不是'作弊'。**系统不做二元判定**。" |
| 1:30–1:50 | **剧本 4**：手写为主、仅局部用 AI 补全 → 系统只高亮那一小段 | 字幕：**"这最重要——局部用了工具，不会判全篇"** 旁白："这是它不会冤枉学生的证明。" |
| 1:50–2:10 | 导出证据包 → 断网 → 校验通过 → 手动改一条事件 → 校验失败并指出第 2 条 | 字幕：**断网也能验，篡改能定位到具体位置** |
| 2:10–2:25 | 能力雷达图 + 班级画像 + 教学建议 | 旁白："它同时是一份正向的教学反馈——告诉老师谁在哪一块需要帮助。" |
| 2:25–2:40 | 隐私说明页：不采代码全文 / 学生可见 / 可删除 / 不做自动化处分 | 字幕：**"数据最小化，决定权在老师"** |
| 2:40–2:55 | 终端：`git clone` → `python scripts/run_demo.py` → 四个剧本输出 | 字幕：**零第三方依赖，Python 3.9+ 直接跑** |
| 2:55–3:00 | 仓库地址 + 一句话 | 字幕：**"看过程，不看文本。"** |

---

## 录制要点

1. **横屏** 1080p（课堂投影场景）；
2. **必须出现"它不能做什么"**：至少一句"逐字重敲进编辑器这种情况，它检出不了"——教师评委极看重这一点；
3. **剧本 4 放在倒数第二个高潮位**，它是全片最有说服力的一幕；
4. 不出现"99% 检出率"之类的数字——当前全部为模拟数据，**未实测不得对外发布**；
5. 结尾字幕：仓库地址 + `python scripts/run_demo.py`。
